# Game-Tic-Tac-Toe
# 🎮 Tic-Tac-Toe Game (Cờ Caro 3x3)

Chán chán nên làm một game nho nhỏ! Đây là trò chơi **Tic-Tac-Toe** (Cờ Caro 3x3) trực tuyến được viết bằng HTML, CSS và JavaScript thuần, hỗ trợ chơi trực tiếp trên trình duyệt máy tính và điện thoại.

---

## 🚀 Chơi thử trực tuyến
👉 **[Nhấp vào đây để chơi ngay](https://khoai-lang-20.github.io/tic-tac-toe/)**

---

## ✨ Tính năng nổi bật
* 🎨 **Giao diện hiện đại:** Thiết kế tối giản, màu sắc trực quan, hiệu ứng mượt mà.
* 👥 **Chơi 2 người (2 Players):** Đổi lượt linh hoạt giữa X và O.
* 🏆 **Tự động phân thắng bại:** Hệ thống tự phát hiện chuỗi thắng (ngang, dọc, chéo) hoặc hòa cờ.
* 🔄 **Nút Chơi lại (Restart):** Bắt đầu ván mới nhanh chóng chỉ với 1 chạm.
* 📱 **Hỗ trợ di động:** Tương thích tốt trên cả điện thoại và máy tính.

---

## 🛠️ Công nghệ sử dụng
* **HTML5:** Tạo cấu trúc khung bàn cờ.
* **CSS3:** Trang trí giao diện, đổ bóng, hiệu ứng tương tác.
* **JavaScript (ES6):** Xử lý logic lượt chơi, kiểm tra điều kiện thắng/hòa.
* **GitHub Pages:** Lưu trữ và chạy trang web trực tuyến.
